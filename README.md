# peluqueria---SmartStyle
Sistema de Gestión Integral para Peluquerías “SmartStyle”
1. Descripción General del Negocio

La cadena de peluquerías “SmartStyle” cuenta con varias sedes en diferentes distritos y actualmente maneja sus procesos de manera manual mediante agendas físicas y archivos en Excel. Esto ha generado problemas en la organización de citas, control de clientes, seguimiento de servicios realizados, gestión de productos y control de pagos.
Debido al crecimiento del negocio, la gerencia ha decidido implementar un sistema informático que permita centralizar y automatizar toda la información operativa y administrativa de la peluquería.
El sistema deberá funcionar como una plataforma integral que permita registrar clientes, gestionar citas, controlar servicios, administrar empleados, manejar inventario y generar reportes de ventas.

2. Problemática Actual

Actualmente la peluquería presenta los siguientes inconvenientes:
Duplicidad de reservas de citas.
Pérdida de información de clientes frecuentes.
Falta de control del historial de servicios realizados.
Desconocimiento del stock real de productos.
Dificultad para calcular comisiones de estilistas.
Errores en los cobros y métodos de pago.
Ausencia de reportes de ingresos y servicios más solicitados.

3. Objetivo del Sistema

Desarrollar un sistema de gestión para peluquerías que permita:
Automatizar el registro de citas.
Administrar información de clientes y empleados.
Gestionar servicios y promociones.
Controlar inventario de productos.
Registrar ventas y pagos.
Generar reportes administrativos y operativos.

4. Alcance del Sistema
El sistema abarcará los siguientes módulos:

Módulo de Clientes
- Registrar clientes.
- Actualizar datos personales.
- Consultar historial de servicios.
- Identificar clientes frecuentes.

Módulo de Empleados

- Registrar estilistas y personal.
- Asignar horarios.
- Calcular comisiones.
- Consultar desempeño.

Módulo de Servicios

- Registrar tipos de servicios:
- Corte
- Tinte
- Manicure
- Pedicure
- Tratamientos capilares
- Definir precios y duración.

Módulo de Citas

- Reservar citas.
- Reprogramar citas.
- Cancelar citas.
- Validar disponibilidad de estilistas.

Módulo de Ventas y Pagos

- Generar comprobantes.
- Registrar métodos de pago.
- Calcular montos totales.
- Aplicar descuentos o promociones.

Módulo de Inventario

- Registrar productos.
- Controlar stock.
- Registrar entradas y salidas.
- Alertar productos agotados.

Módulo de Reportes

- Reportes de ingresos.
- Servicios más solicitados.
- Clientes frecuentes.
- Productos más utilizados.
- Comisiones por empleado.
